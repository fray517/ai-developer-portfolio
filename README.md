# AI Developer Portfolio — Applied AI Studio

Одностраничное портфолио независимого AI-разработчика. Лендинг представляет три проекта в разработке. Иллюстрации в карточках показывают концепции, а связаться с автором можно через Telegram.

[Открыть портфолио на GitHub Pages](https://fray517.github.io/ai-developer-portfolio/)

## Локальный просмотр

Откройте `index.html` в браузере. HTML, CSS, JavaScript и SVG встроены в страницу. Установка зависимостей и сборка не требуются. Проверки адаптивности выполнялись через локальный HTTP-сервер.

## Структура

- `index.html` — исходный код и графика лендинга.
- `docs/TZ.md` — техническое задание v0.3.
- `docs/DESIGN_DOCUMENT.md` — дизайн-концепция v0.2.
- `docs/DESIGN_RULES.md` — дизайн-правила v0.2.
